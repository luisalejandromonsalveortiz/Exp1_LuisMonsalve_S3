Propósito del proyecto El propósito de este sistema es resolver la desorganización, duplicación y falta de trazabilidad de los datos de contacto en Llanquihue Tour. 
Mediante el paradigma de Programación Orientada a Objetos (POO), el software centraliza y estandariza la información de clientes, guías y operadores usando mecanismos de herencia y composición.
Esto establece una base de datos lógica, escalable y segura con miras a la futura implementación de un sistema de persistencia completo. Desde la terminal de comandos (Consola)
Abre tu terminal y posiciónate en la carpeta raíz del proyecto (donde se encuentra el directorio src).
Compila todas las clases del proyecto ejecutando: bash javac -d bin src/cl/llanquihuetour/model/.java src/cl/llanquihuetour/app/.java Usa el código con precaución.
Ejecuta la clase principal (Main) apuntando al directorio compilado: bash java -cp bin cl.llanquihuetour.app.Main Usa el código con precaución. Opción 2: Desde IntelliJ IDEA (Recomendado)
Abre la carpeta del proyecto en IntelliJ IDEA.
Espera a que el IDE indexe los archivos (verás que la carpeta src se marca en color azul como Sources Root).
Busca el archivo Main.java en la ruta src/cl/llanquihuetour/app/.
Haz clic derecho sobre el archivo o dentro del código y selecciona Run 'Main.main()' (o presiona Shift + F10).
La salida estandarizada aparecerá inmediatamente en la consola inferior de la pantalla. Dime si necesitas agregar detalles extra a la documentación, 
como por ejemplo: • Una explicación detallada de cómo se aplicó el encapsulamiento (private/public). • El diagrama de clases en formato de texto (Mermaid) para visualizar la herencia y composición.
